#configurando o kibana no elastic
assim que inicar o elastic o kibana vai parar por que precisa criar o usuari para o mesmo 
para criar o usuario para o kibana execute o arquivo que esta no script/init.bash
entre na pasta cd script
execute o bahs ./init
como você pode ver ele vai criar o usuario no elastic
depois disso corre para o abraço

#configurando o setap para APM no kibana e elastic
Management → Fleet
Se for a primeira vez:
Clique em "Set up Fleet"
Aceite os defaults
Aguarde finalizar
Instale a APM Integration
Fleet → Integrations → APM → Add APM
Não precisa Agent ainda
Só instalar a integração
Isso cria automaticamente:
Index templates
Data streams
Pipelines
Dashboards
